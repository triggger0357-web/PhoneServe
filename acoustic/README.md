# Acoustic Data Transmission Module

This directory contains utility scripts for air-gapped, data-over-sound wireless transmission and node bootstrapping.

## Scripts
* **tx_chat.py**: Modulates binary data packets into an audio stream for acoustic transmission.
* **rx_chat.py**: Captures incoming audio streams via microphone and demodulates them back into binary packets.

## Usage
Ensure microphone and speaker permissions are granted within Termux before running transmission tests.
